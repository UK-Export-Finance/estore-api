CRITICAL PATH ANALYSIS
══════════════════════════════════════════════════════════════════════════════

The critical path (longest chain of dependencies) is:

  TypeScript (fix error) → TypeScript (update) → NestJS Core → NestJS Features → Testing

Time components:
  - Fix existing error: 30 min
  - TypeScript update: 1-1.5 hours (may reveal more type errors)
  - NestJS Core: 1-1.5 hours
  - NestJS Features: 2-3 hours (longer due to API review needed)
  - Testing: 1-2 hours
  - Validation/Troubleshooting: 2-4 hours (variable)
  
Total critical path: 8-12.5 hours


PARALLEL OPPORTUNITIES
══════════════════════════════════════════════════════════════════════════════

After Step 3 (TypeScript update), Steps 4 & 5 can be done together:
  - Update NestJS core packages: 1-1.5 hours
  - Update NestJS features: 2-3 hours
  - Run tests after both: 1 hour
  
  Total: 4-5.5 hours (instead of sequential 3-4.5 hours)
  
  But caution: Updates must be atomic commits for debuggability


ROLLBACK STRATEGY
══════════════════════════════════════════════════════════════════════════════

At any point, if issues are unresolvable:

  Level 1 (Last commit):
    git reset --hard HEAD~1
    npm install --legacy-peer-deps

  Level 2 (This feature branch):
    git checkout main
    git branch -D chore/update-dependencies
    npm install --legacy-peer-deps

  Level 3 (Last known good):
    git checkout <last-working-commit>
    npm install --legacy-peer-deps

  Prevention: Always commit after each major package update


TESTING STRATEGY
══════════════════════════════════════════════════════════════════════════════

After each phase:

  Phase 2 (Fix error):
    npm run type-check

  Phase 3 (TypeScript):
    npm run type-check

  Phase 4 (NestJS Core):
    npm run build
    npm run type-check
    npm run lint

  Phase 5 (NestJS Features):
    npm run unit-test  # Run only tests for affected modules:
    # e.g., --testPathPattern="config|cache|axios|passport|swagger"

  Phase 6 (Testing packages):
    npm run unit-test
    npm run api-test

  Phase 7 (Clean install):
    Full validation suite:
    npm run type-check && npm run build && npm run lint && \
    npm run unit-test && npm run api-test
